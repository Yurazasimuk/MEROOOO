# MERO AI Stylist 

##  Elevator Pitch (Концепція)
**Проблема:** Сучасні покупці інтернет-магазинів одягу часто губляться у великих каталогах. Вибір образу для конкретної події (вечірка, ділова зустріч, дощова погода) забирає багато часу, що призводить до відкинутих кошиків та втрати клієнтів.
**Рішення:** MERO AI Stylist — це інтелектуальний віджет-помічник, інтегрований безпосередньо в інтерфейс магазину. Він працює як персональний стиліст: аналізує запит користувача, враховує наявний контекст (базу товарів магазину) і миттєво генерує персоналізовану пораду, повертаючи не просто текст, а конкретні ID товарів для їх подальшого відображення.

##  Цільова аудиторія
* Клієнти інтернет-магазину MERO, які цінують свій час.
* Користувачі, які шукають готові капсульні рішення або потребують допомоги у комбінуванні речей.
* Люди, які роблять покупки під конкретні події (свята, відпустки, зміни сезону).

##  Технічна реалізація та ШІ-паттерни
Проєкт використовує API **Google Gemini 2.5 Flash**. 
Реалізовано просунутий ШІ-паттерн: **Контекстна генерація зі строгим форматуванням (Data Extraction / Structured Output)**.
* **Ізоляція інструкцій від даних:** ШІ отримує чітко структурований словник наявних товарів (`productsDatabase`) і працює виключно в його межах.
* **Встановлення жорстких меж формату:** Завдяки налаштуванню `responseMimeType: "application/json"`, модель примусово повертає сирий JSON без маркдаун-тегів (галюцинацій форматування). Це дозволяє бекенду легко інтегрувати відповідь в UI.
* **Стійкість до відмов (Fail-Safe):** Реалізовано блоки `try-catch`. У разі помилки API користувач бачить дружнє повідомлення (Елегантна деградація), а не технічний збій.

##  Інструкція із запуску 

1. **Клонування / Завантаження:**
   Завантаж файли проєкту (або склонуй репозиторій) на свій комп'ютер. Усі файли (HTML, CSS, JS) мають знаходитись в одній директорії.
2. **Отримання API-ключа:**
   * Перейди на [Google AI Studio](https://aistudio.google.com/).
   * Згенеруй новий API-ключ.
3. **Налаштування ключа:**
   * Відкрий файл `script.js`.
   * Знайди змінну `GEMINI_API_KEY` (на початку файлу) і встав свій ключ: `const GEMINI_API_KEY = "ТВІЙ_КЛЮЧ";`.
4. **Запуск:**
   Проєкт працює без складного бекенду. Просто відкрий файл `index.html` у будь-якому  браузері.
